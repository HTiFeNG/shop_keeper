# 店铺管家（shop_keeper）

商品管理 × 营业额记录 合并 App —— 一站式守店工具（Android + Web PWA）。

**当前版本：4.0.0**（拼音搜索 + 跨日期查账 + 自定义区间/年度统计 + 批发价 + 欠账本 + 坚果云跨端同步；完整变更见下方「版本变更」）

## 功能概览

### 营业额（首页）
- 日期切换记账；**跨零点自动切到新的一天**（柜台手机整夜开着也不会把早上的账记进昨天）。
- 从商品库选品自动带价；**扫码直接记账**（仅 Android）。
- **零售 / 批发两种计价方式**：选品时可切到批发价，明细行上的价签按钮可随时在「零售价 ⇄ 批发价」间切换并重算金额；同商品不同计价方式**不会**被合并成一行。
- 数量步进、单价编辑；总价默认 = 单价 × 数量，手动改写即解绑（抹零/改价）。
- 「最近常卖」快捷条：按最近 30 天销量自动生成，点一下记一笔，**不依赖手工加星**；有星标商品时优先显示星标。
- 删除行 5 秒内可撤销。
- 日合计大字：当日营业额 + 种类数 + 件数，固定悬浮在明细上方。

### 查账（跨日期明细搜索）
- 首页搜索图标进入；一次搜**所有日期**的明细（商品名 / 拼音首字母 / 品牌 / 条码 / 金额）。
- 时间范围快捷筛：今天 / 本周 / 本月 / 近 30 天 / 自定义区间。
- 结果按日期分组、组内显示小计；点日期可直接跳回那天的记账页。

### 统计
- 三种口径切换：**按月 / 自定义区间 / 按年**。
- 月视图：月总营收 / 日均 / 最高日 / 总件数四宫格，柱状图点柱子跳到当天明细，环比，商品排行前 10。
- **自定义区间**：任选起止日期，环比基准是「上一个等长区间」，避免拿 3 天去比 30 天。
- **年度总览**：12 个月完整折线/柱状，最忙的月份、平均月营收（按有营收的月份平均，不被空月拉低）。
- **估算毛利**：按「零售价 − **售出时的参考进价快照**」计算，之后修改商品进价不会改写已过去月份的毛利；亏本销售如实显示为负数；未填进价的明细会单独提示条数。

### 欠账本（赊账台账）
- 「更多」菜单进入。登记 客户 / 金额 / 日期 / 备注，支持标记已结清与撤销。
- 三种视图：未结清 / 已结清 / **按人汇总**（谁欠得多一目了然）；顶部显示未收回总额与逾期（超 30 天）提示。
- ⚠️ 欠账**不计入营业额**，只是台账 —— 不然「卖出去了」和「钱到账了」会被算两遍。要算营业额请在记账页正常记一笔。

### 跨端同步（坚果云 WebDAV）
- **不需要自建服务器**：用你现有的坚果云账号做中转，手机 ↔ 电脑互传备份。
- 配置：坚果云 → 安全选项 → 添加应用密码，填账号 + 应用密码 + 远端路径。
- 动作：测试连接 / 上传到云端 / 从云端恢复。
- 安全设计：**只读比对，绝不静默覆盖**。启动时会检查云端备份是否更新，若更新则弹窗给你选「查看并恢复 / 忽略」；恢复前照例存一份本机快照，可撤销。
- ⚠️ Web 端因浏览器 CORS 限制不可用，同步只在 Android / 桌面端生效；Web 端仍可用手工导入导出的 JSON 备份。

### 数据安全
- 全量备份 / 恢复（JSON）：恢复前**预览内容**（商品数 / 天数 / 明细条数 / 欠账条数 / 导出时间），恢复时**自动存一份恢复前快照**，可一键「撤销上次恢复」。
- 备份提醒：超过 7 天没备份会在首页提示，一键备份。
- 启动容错：单条数据损坏只跳过那一条，不再整体清空；整段损坏会明确报错而不是显示「暂无商品」。
- 保存失败会显式提示（不再「界面说已保存、实际没写进去」）。

### 商品管理
- 商品模型：名称、类别、品牌、条码、批发价、参考进价、零售价、星标收藏（编号自动生成）。
- **实时搜索升级**：商品名（含**拼音全拼 / 首字母**）/ 品牌 / 条码，按相关度排序 —— 完全匹配 > 条码 > 前缀 > 包含 > 首字母 > 全拼 > 品牌。输入 `kl` 能找到「可乐」，`nfsq` 能找到「农夫山泉」。
- 列表内直接加 ★；分类管理（增删改排序）；手机端顶部横滑 Chips 提供可见的「管理」入口，不必长按。
- 批量操作、扫码（仅 Android）。
- 条码重复会被拒绝（否则扫码永远只命中第一个商品）。
- 商品表单：价格格式校验、零售价为 0 二次确认、未保存返回时提醒。

### 导出
- Android：Excel 双 Sheet（当日明细 + 月度汇总）经系统分享；Web：CSV 浏览器下载。
- 商品 CSV 导入 / 导出（导入会校验「编号」表头，选错文件不再静默导入垃圾数据）。
- 导出/导入失败会给出人话提示并可重试。

### Web / PWA
- 可「添加到主屏幕」，独立窗口运行，带启动遮罩（首帧前不白屏）与安装提示条。
- manifest 补齐 `id` / `scope` / `lang` / `display_override` / `orientation: any` / `categories`，iOS 侧补齐 `apple-touch-icon` 与状态栏 meta。

## 版本变更

### 4.0.0
- **拼音首字母搜索**（新依赖 `lpinyin`）：商品搜索与查账页都支持拼音全拼 / 首字母，并按相关度打分排序。词级缓存（上限 4000）避免每次按键都重算。
- **查账页（跨日期明细搜索）**：新增 `sales_search_page.dart`，一次搜所有日期的明细，支持金额数字匹配与时间范围快捷筛。
- **统计支持自定义区间 + 年度总览**：`monthly_stats_page.dart` 重构为三口径（月 / 区间 / 年），区间环比对齐「上一等长区间」；年度视图给出 12 个月完整序列。
- **批发价字段落地**：新增 `SalePriceMode`（retail / wholesale），商品模型里的批发价从死字段变为可用；明细行 / 表格新增计价列与切换按钮，切换时重算「单价 × 数量」。
- **欠账本**：新增 `Credit` 模型与 `credit_page.dart`，欠账不参与营业额统计。
- **坚果云 WebDAV 跨端同步**：新增 `nutstore_sync.dart` 与 `sync_settings_page.dart`，无需服务器；只读比对、不静默覆盖。
- **架构拆分**：`store_service.dart` 从 913 行的 god object 拆成门面 + 纯函数模块（`stats_calculator.dart` / `backup_codec.dart` / `nutstore_sync.dart` / `store_constants.dart`），**公开 API 零破坏**。
- **测试分层**：原先单文件 739 行的 `widget_test.dart` 拆为 `test/{helpers,models,services,utils,widgets}` 七个小组，新增拼音 / 区间 / 年度 / 批发 / 欠账 / 同步的覆盖（112 个用例）。
- **CI**：新增 `.github/workflows/ci.yml`，push / PR 自动跑 `flutter analyze` + `flutter test` + `flutter build web` 并产出 web artifact。
- **PWA 增强**：启动遮罩、安装提示条（7 天内不再打扰）、manifest 与 iOS meta 补齐。
- **数据安全加固（4.0.0 评审后补）**：
  - 恢复备份写盘中途失败时，现在会**内存 + 磁盘一起回滚**。旧实现只回滚内存，磁盘上会留下「备份的商品 + 原有的营业额」这种撕裂状态，用户重启后再也找不回原数据。
  - 备份解析容忍 **UTF-8 BOM**（文件被记事本之类另存过后仍能恢复）；「从备份文件恢复」是灾后唯一兜底通道，不能因为一个 BOM 失效。
  - CSV 导入时价格留空（解析为 0）**不再覆盖已有价格**，避免批量导入把填好的零售价/进价静默清零。
  - 手动改价的行被合并后，单价会同步成实际单价，让「单价 × 数量 = 总价」重新自洽。

### 3.0.2
- **商品搜索支持品牌**：商品页的实时搜索现在按「商品名 / 品牌 / 条码」匹配（选品弹窗同步支持），搜索框提示语一并更新。
- **记账后自动定位到新行**：新增或合并一笔后，明细视图会自动滚动到那一行，商品一多也不用自己往下翻找。为此明细列表改为非懒构建（`Column + SingleChildScrollView`）并给每行挂了 `GlobalKey`——`ListView` 是懒构建的，视口外的行不在树里，`ensureVisible` 定位不到（新增行在末尾，恰恰常落在视口外）。
- **修复选品弹窗与星标卡片的水波纹被遮挡**：带底色的 `DecoratedBox` 会挡住 `ListTile` 的点按反馈（Flutter 会抛相应断言），按官方建议给 `ListTile` 垫了一层透明 `Material`，点选商品恢复点按反馈。

### 3.0.1
- **更换应用图标**：新的店铺图案。素材做了规范化——原图整体右偏 6.9%、只占画布 44%，已重新居中并放大到 82%，以匹配自适应图标的 `inset 16%` 规格（否则图标会偏右且明显偏小）。同步重新生成 Android 各密度、Web 与 favicon 图标。
- **当日合计改为悬浮固定**：合计条移到明细列表**上方固定**，明细再多、上下翻动时也始终能看到当天金额；日期一并写在条内。同时把高度从约 78dp 压到约 54dp，把空间还给明细行。
- **去掉商品页「进价未填」提示**（选品弹窗里的同一提示也一并去掉）。月度统计里「有 N 条明细没填进价，未计入毛利」保留，因为它解释的是毛利为何算不全。
- **修复两处窄屏溢出**：数量步进行在 360dp 屏溢出 3px（上一版把触控区放大到 48dp 后出现）；悬浮合计条在金额较大或系统字号调大时会溢出。两处都改为弹性布局，并补了回归测试。

### 3.0.0
- **移除库存功能**：不再显示/编辑/扣减库存。`Product.stock` 字段仍保留并随备份原样读写，仅为了不销毁已有数据；CSV 导出不再包含「库存」列，但仍兼容旧 9 列文件导入。
- **毛利口径修正**：改为在售出时快照参考进价；不再丢弃亏本销售（不再用 `margin > 0` 过滤）；营收取 `totalPrice`，与营收统计同口径。
- **修复数据丢失风险**：加载容错、商品编号不再回收（避免历史销售改指到别的商品）、恢复备份改为「全部解析 → 存快照 → 替换 → 写入失败回滚」、持久化失败不再静默。
- **修复记账错误**：跨零点自动换天；删除行的撤销不再串日期；手动改价的行再次合并时金额等比放大（原先件数 +1 但营业额不变）。
- **可读性/可用性**：多处文字与图标对比度提升到 WCAG AA（当日合计、次要文字、分类选中态、排行榜名次等）；触控区统一到 ≥48dp；次要字号下限提高到 13；失败提示改为一句人话且可重试。

### 2.0.2
- 修复深色模式下的配色错乱：App 固定浅色主题，原生启动主题与窗口底色统一为暖米白。

## 技术栈

Flutter（Dart ^3.13）、shared_preferences / localStorage 持久化（键名 `sk_` 前缀）、fl_chart 图表、excel 包（仅非 Web 端 conditional import）、lpinyin（拼音搜索）、http（坚果云 WebDAV）。

## 目录结构

```
lib/
  models/        数据模型（Product / Sale / Credit / 统计）
  pages/         页面（首页记账 / 商品 / 统计 / 查账 / 欠账本 / 同步设置）
  services/
    store_service.dart     门面：唯一的状态容器与持久化入口
    stats_calculator.dart  纯函数：月 / 区间 / 年度统计
    backup_codec.dart      纯函数：备份编解码（v2/v3 兼容）
    nutstore_sync.dart     坚果云 WebDAV 客户端
    store_constants.dart   共享常量（打散循环依赖）
  utils/         search.dart（拼音搜索索引）/ format / date_utils
  widgets/       复用组件
test/
  helpers/       测试环境（重置存储 / 注入数据 / 视口）
  models/ services/ utils/ widgets/   分层用例
```

## 构建

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --release   # Android APK → build/app/outputs/flutter-apk/
flutter build web --release   # Web 版 → build/web/（可安装 PWA）
```

> Windows 下若 `flutter` 命令报 PATH 异常，先 `export PATH="/usr/bin:/bin:/c/Windows/System32:$PATH"`；本机构建前需 `unset NODE_OPTIONS` 与各类代理变量。

## 开发说明

- 视觉规范统一在 `lib/theme/app_theme.dart`，页面不要散落硬编码颜色/字号。
- App **只提供浅色主题**并锁定 `ThemeMode.light`：全部页面颜色都取自浅色常量，跟随系统切深色会出现「页面浅、组件深」的错乱配色。
- 金额一律走 `lib/utils/format.dart`；日期一律走 `lib/utils/date_utils.dart`。
- 搜索一律走 `lib/utils/search.dart` 的 `SearchIndex`，不要在页面里手写 `contains`。
- 新增/修改存储相关的逻辑，请同步补 `test/services/` 下的用例；`test/helpers/store_test_env.dart` 提供 `resetStore` / `resetStoreWith` / `useSmallPhone` / `pumpApp`。
- 数据默认只存在本机；开启坚果云同步后云端会有一份 JSON 备份。**Web 端没有同步能力**，改动存储字段时注意 `backup_codec.dart` 的版本号（`kBackupVersion`）与向后兼容。
